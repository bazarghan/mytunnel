# HLTunnel v1.0.0

نخستین نسخه‌ی مستقل **`hltunnel` (`HLTunnel`)**:

- ریبرند کامل پروژه (CLI، سرویس systemd، مسیر `/etc/hltunnel`، جداول `nftables`، نام اینترفیس‌ها با پیشوند `hl-`/`hlx-`، لایه‌ی مبهم‌سازی `HLObfs`، پنل وب و مستندات) به **`HLTunnel`**.
- حذف کامل تبلیغات، روت‌ها/کلیدهای اسپانسری، تله‌متری، و پیوندهای پروژه اصلی.
- به‌روزرسانی سیستم نسخه‌گذاری و آپدیت پنل/نصاب برای مخزن `bazarghan/mytunnel` با پشتیبانی کامل از مقایسه‌ی استاندارد SemVer (شامل تگ‌های `vX.Y.Z` و پسوندهای پیش‌انتشار).
- بازسازی و پاک‌سازی معماری تعریف پروتکل‌ها در `internal/config/kind.go` و رابط درایور فضای کاربر در `internal/daemon/userspace.go` همراه با راهنمای فنی [`docs/ADDING_PROTOCOLS.md`](../ADDING_PROTOCOLS.md) برای افزودن سریع پروتکل‌های جدید.
